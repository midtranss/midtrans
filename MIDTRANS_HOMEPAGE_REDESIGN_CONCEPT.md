# MIDTRANS Homepage Redesign Concept

## Purpose

This is a concept document only. It does not modify the homepage or authorize implementation.

The homepage should become the strongest visual entry point for MIDTRANS as an integrated logistics and supply chain company.

## Current Homepage Findings

The current homepage contains strong business content:

- Freight forwarding for Syria, Dubai, China, UAE and Jebel Ali corridors
- Route validation
- Document readiness
- Customs exposure control
- Tools and quote actions
- Service summaries
- Trust signals and FAQ

However, the visual presentation does not fully match the operational strength of the content.

## Main Homepage Weaknesses

### Hero

The hero communicates what MIDTRANS does, but it does not yet create a premium international logistics impression.

Issues:

- Too much depends on text.
- Visual identity is not strong enough.
- Key business pillars are present but not visually staged.
- Tracking, quote, tools, and contact actions need a cleaner hierarchy.

### First Screen

The first screen should immediately answer:

- Who is MIDTRANS?
- What corridors and services does it control?
- Why trust MIDTRANS before cargo moves?
- What action should the user take?

Current structure answers these, but not with enough visual force.

### Service Presentation

The services section lists many capabilities but should feel more like an integrated logistics system:

- Sea freight
- Air freight
- Land freight
- Customs clearance
- Warehousing
- Consolidation
- Project cargo
- Vehicles
- Packing and handling

The current layout risks feeling like a list instead of a connected supply chain.

### Trust Signals

Trust content exists, but it should be elevated visually:

- Established in Damascus in 1998
- China coordination since 2004
- UAE/Jebel Ali capability since 2009
- FIATA/IATA/WCA/PPL references
- Dubai/Jebel Ali/Syria/China corridor experience

These should become a prominent credibility band.

## Recommended Homepage Structure

### 1. Premium Logistics Hero

Recommended hero elements:

- Strong H1 focused on integrated freight execution.
- Short operational subheading.
- Primary CTA: `Request a Freight Quote`.
- Secondary CTA: `Contact MIDTRANS` or `Track Shipment`.
- Visual module showing:
  - origin
  - destination
  - cargo documents
  - customs checkpoint
  - freight modes
  - shipment follow-up

Hero should feel like logistics command, not generic shipping.

### 2. Operational Proof Strip

Immediately below hero:

- Established 1998
- Dubai and Jebel Ali operations
- China coordination
- Sea / air / land / customs
- Digital platform support

This should be a refined horizontal trust strip, not plain text.

### 3. Shipment Planning CTA Block

A compact section explaining:

- Send origin
- Send destination
- Send cargo description
- Send dimensions and weight
- Send documents if available

This supports quote conversion and makes MIDTRANS look process-driven.

### 4. Service Capability Grid

Use a premium 2x or 3x grid:

- Freight forwarding
- Sea freight
- Air freight
- Land freight
- Customs clearance
- Warehousing and consolidation
- Project cargo
- Vehicle shipping
- Digital logistics support

Each card should include:

- icon
- short service name
- 1-2 line value statement
- relevant CTA/link

### 5. Trade Lane Highlight

Show strategic routes without overwhelming the user:

- China to Syria
- Dubai / UAE to Syria
- Jebel Ali to Syria
- Turkey to Syria
- Europe to Syria
- GCC to Syria

Route cards should include:

- origin and destination
- available modes
- customs/document note
- CTA

### 6. MIDTRANS Process Section

Suggested title:

`How MIDTRANS builds a workable shipment plan`

Steps:

1. Cargo facts
2. Route review
3. Document check
4. Customs exposure
5. Freight mode selection
6. Shipment follow-up

This would strongly differentiate MIDTRANS from simple rate sellers.

### 7. Digital Logistics Platform Block

This should be controlled and factual.

Positioning:

`Digital support for shipment visibility, documents and operational follow-up.`

Avoid:

- Overstated AI claims
- Futuristic visuals that do not match freight reality

### 8. Trust and Milestone Section

Use a visual timeline:

- 1998 Damascus establishment
- 2004 China coordination
- 2009 UAE/Jebel Ali capability
- Professional networks
- Current regional lanes

This should look premium and credible.

### 9. Final CTA

Final CTA should be strong:

`Send shipment details for route review`

Include:

- Request Quote
- Contact WhatsApp
- Track Shipment for existing clients

## Homepage Visual Style

Recommended:

- White and soft grey page background
- Deep navy headings
- MIDTRANS blue primary actions
- Controlled green status accents
- Premium cards with soft shadow
- Route and process diagrams
- Real logistics imagery or abstract route graphics

Avoid:

- Heavy dark AI theme
- Generic stock business visuals
- Overcrowded first screen
- Too many equal CTA buttons

## Homepage Mobile Behavior

Mobile homepage should:

- Put H1 and primary CTA early
- Collapse proof strip into 2-column or stacked badges
- Show service cards in one column
- Keep route cards compact
- Keep quote CTA visible but not sticky unless approved
- Avoid long unbroken text blocks

## Recommended Homepage Pilot Scope

Because `/` is protected, homepage redesign should not be the first implementation pilot unless explicitly approved.

Recommended approach:

1. Create static visual mockup only.
2. Review with stakeholder.
3. Apply design system first to a non-home staging page.
4. Return to homepage after component validation.

## Risk Level

High if applied directly to live homepage.

Medium if created as a staging-only design prototype.

## Fit for MIDTRANS

A stronger homepage is necessary, but implementation should be controlled because the homepage is critical for brand, SEO, navigation, and conversion.
