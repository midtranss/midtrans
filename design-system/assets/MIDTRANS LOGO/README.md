# MIDTRANS LOGO

The MIDTRANS identity: a ship's wheel with wings, above the "Midtrans" wordmark in its own script face and the line "Shipping & Services".

| File | Use |
| --- | --- |
| `midtrans-logo-blue.png` | Default. On `surface-page`, `surface-card` and `surface-sunken`. |
| `midtrans-logo-white.png` | On `surface-inverse`, on a `brand-accent` field, and over photography. |
| `midtrans-app-icon-1024.png` | Store listings, social profile, high-density touch icons. |
| `midtrans-app-icon-512.png` | Favicons, app icons, avatars, and anywhere the full lock-up falls below 120px wide. |

**Ink.** These are flat single-ink PNGs on transparency and carry their ink in the file — an `<img>` cannot inherit a text colour, so never try to recolour them with CSS. Pick the file that suits the ground instead. The blue file's ink measures `#007DC6`, one step off the stated brand `#007DC5`; the difference is not visible in use, but re-cut artwork should settle on one value. The "Shipping & Services" line is near-black `#050708` in the blue file.

**Clear space and size.** Keep `space-4` clear on all four sides, measured from the widest point of the wings. The full lock-up is not used below 120px wide; use an app icon there.

**Do not** rotate, stretch, outline, add a shadow to, or recolour the mark, place it on a busy photograph without a `surface-inverse` scrim, or re-set the wordmark in another typeface. The mark is non-directional: it does **not** mirror on Arabic RTL pages.

**Format.** PNG raster only. Vector artwork is needed before print, large-format or favicon production; record it here when it is available.
